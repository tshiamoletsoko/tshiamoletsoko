## 🚀 Projects

### 📚 [LazyBooks: AI-Powered Second-Hand Textbook Marketplace](https://github.com/tshiamoletsoko/LazyBooks)

> C# · ASP.NET MVC · Razor Pages · Ollama · REST APIs

A web app where university students buy and sell second-hand textbooks, with an AI study assistant built in. I led the team, designed the UI/UX, built the core backend, connected a locally run Ollama model through custom REST APIs, and pitched the final product to the judges and sponsors.

**Hackathon:** 🥉 3rd Place, IIE Varsity College Waterfall Hackathon

---

### 💧 [Water Warriors: Mission Management App](https://github.com/tshiamoletsoko/WaterWarriors)

> Kotlin · Android · Firebase Authentication · REST APIs

An Android app for NPO admins and team leaders to plan community missions and charity events. It has secure sign-in, real-time data, and a backend API for mission assignments, syncing and event tracking. The UI is built to be quick and easy to use out in the field.

---

### ✅ [Habit Tracker: API-Driven Android App](https://github.com/tshiamoletsoko/HabitTracker)

> Kotlin · Android Studio · Retrofit · MVC

A habit-tracking app that saves data through an API using Retrofit. Built with MVC to keep the code clean and easy to grow.
